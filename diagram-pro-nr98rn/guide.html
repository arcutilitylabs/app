SECTION 01
4つの図解モードと特性
・リング・サイクル（2〜12分割） 手順やPDCA、構成比を表す円環図です。内径を0にすると円グラフ、数値を上げるとドーナツ型になり、エッジ矢印で循環の流れを表現できます。
・レイヤー（2〜6層） 中心のコア概念から外側へ段階的に広がる同心円図です。理念の浸透やターゲット層の整理に適しています。
・サテライト（2〜12分割） 中心テーマ（CORE）から周囲へ複数の要素を放射状に展開する関連図です。中心円・子円のサイズや接続線の太さを調整できます。
・レーダー（3〜12軸） 複数項目のバランスや評価軸を表す多角形チャートです。三角形から十二角形まで軸数を自在に変更でき、文字位置の距離も調整できます。
SECTION 02
形状スライダーと基本テキスト
・デザイン確認用背景設定（ホワイト／ブラック） 作業中のプレビュー背景を白／黒で切り替えます。どちらを選んでいても、保存される画像（PNG等）の背景は常に「透明」になります。
・パーツ間隔 ／ リング隙間 隣り合うセグメントや階層の間の余白（隙間）をピクセル単位で美しく整えます。
・回転角度（-180°〜+180°） 図解全体を回転させ、先頭項目や頂点の位置を配置したい角度へ正確に合わせられます。
・7種のフォント＆文字色切替 標準ゴシック、UDゴシック、丸ゴシック、明朝体など7種のフォントと、白文字／ダーク文字を一括で切り替えられます。
SECTION 03 & 04
カラー生成とテキスト入力の工夫
・カスタム基準色からのパレット自動生成 5種の厳選プリセットに加え、「カスタム基準色」から好きな1色を選ぶだけで、調和する6色のグラデーションパレットを自動生成します。
・番号アイコンクリックでの個別色変更 テキスト入力欄の左にある「色付き番号アイコン（1, 2, 3... または C）」をクリックすると、そのパーツだけ個別の色へ自由に変更できます。
・スラッシュ「/」による美しい複数行改行 ラベル入力欄に「/（半角スラッシュ）」を入れると、その位置で自動的に改行されます（例：「01 / 計画 / Plan」で3段組の中央揃えになります）。

『Arc Diagram Generator Pro』は外部ライブラリに依存しない単一HTMLファイルで構築されています。以下のボタンから最新版ファイルをPCに保存しておくと、インターネット接続のない環境でもそのままブラウザで動作します。また、AIでカスタマイズする際のベースコードとしてもお使いいただけます。

普段お使いのAIに以下の指示プロンプトとPRO版のHTMLコードを渡すだけで、自社のコーポレートカラーを初期パレットに登録したり、よく使う業務フレームワークを初期ラベルに設定した「自分専用エディション」を簡単に生成できます。 

以下のHTMLコードは、単一ファイルで動作する図解作成ツール「Arc Diagram Generator Pro」です。
既存のレイアウト構造、SVG描画ロジック、およびエクスポート機能（クリップボードコピー・SVG・PDF・PNG・JSON保存）を一切損なうことなく、以下の【希望する変更内容】のみを反映した完全なHTMLコードを出力してください。

【希望する変更内容】
1. 初期カラーパレット（defaultPalettes配列の先頭、または新規追加）に以下の配色を追加してください：
   ・パレット名：My Brand Palette
   ・カラーコード（6色）：#1e3a8a, #1d4ed8, #2563eb, #3b82f6, #60a5fa, #93c5fd

3. 起動時の初期テキストラベル（state.labels配列の先頭4つ）を以下に変更してください：

   ・2つ目：02 / 戦略策定 / Strategy
   ・3つ目：03 / 施策実行 / Execution
   ・4つ目：04 / 効果検証 / Review

【出力ルール】
・省略（「// 既存のコードと同じ」など）は一切行わず、最初から最後までそのまま保存してブラウザで動く完全なHTMLコードとして出力してください。

STEP 03 テキストエディタ（メモ帳・VS Code等）で直接書き換える場合のガイド

AIを使わずに、ご自身でHTMLファイルをメモ帳やコードエディタで開いて初期設定を書き換える場合は、`<script>` タグ直下にある以下の変数（`defaultPalettes` および `state`）の値を変更して上書き保存するだけで即座に反映されます。

変更したい項目 コード内の変数名 書き換え方法・具体例
配色パレットの追加・変更 const defaultPalettes 配列内の { name: 'パレット名', colors: ['#色1', '#色2', '#色3', '#色4', '#色5', '#色6'] } を書き換えるか、新しい行を追加します。6色の16進数カラーコードを指定してください。
起動時の図解モード state.mode 'ring'（リング）、'layer'（レイヤー）、'satellite'（サテライト）、'polygon'（レーダー）のいずれかを指定します。
起動時の初期ラベル文字 state.labels 配列内の文字列（'01 / 計画/Plan' など）を普段よく使う項目名に書き換えます。改行したい位置には / を入れておきます。
起動時の初期数値（Weights） state.values 数値反映モードを最初からONにしたい場合は、state.useWeights: true に変更し、values: [40, 25, 20, 15, ...] の数値を変更します。
